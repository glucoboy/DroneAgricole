# Décisions d'architecture (ADR)

Chaque décision structurante est décrite dans un fichier numéroté :

```text
ADR-0001-titre-court.md
```

Le document précise le contexte, la décision, les alternatives, les conséquences et le statut. Les décisions pressenties dans les documents préliminaires ne deviennent définitives qu'après validation ou création d'un ADR accepté.
