# Copie candidate du cartographe

Ouvrir [Prototype_Cartographe.FCStd](assemblages/Prototype_Cartographe.FCStd)
avec FreeCAD et l'atelier Cables installé. Garder ensemble les répertoires
`assemblages`, `sous_assemblages`, `pieces` et `verification` pour conserver
les liens relatifs. Dans SA07, `F16` pointe sur `Cable002` du candidat et
`ProtectionF38` est la paroi ovale de réservation. Les autres variantes de
`verification/candidats` peuvent être ouvertes séparément.

Les réserves d'intégration et les contrôles sont dans
[DOC-MEC](../../../docs/architecture/ARCHITECTURE_MECANIQUE.md#reconstruction-faisceaux)
et [DOC-VAL](../../../docs/VALIDATION_QUALIFICATION.md#validation-reconstruction-faisceaux).
