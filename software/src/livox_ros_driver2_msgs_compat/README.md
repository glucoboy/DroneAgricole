# Interfaces Livox de compatibilité

Ce paquet fournit uniquement les deux définitions de messages MIT de `Livox-SDK/livox_ros_driver2` requises à la compilation de la branche ROS 2 officielle de FAST-LIO.

Il ne contient aucun pilote matériel. Il est adapté au benchmark hors ligne. Lors de l'intégration d'un LiDAR Livox physique, il devra être remplacé par le pilote officiel complet, figé et testé séparément.
