# Recherche

Ce répertoire accueille les ressources techniques nécessaires aux recherches
du projet : bibliographie structurée, configurations et preuves légères.
Les données lourdes et résultats restent dans les emplacements prévus par
la politique du dépôt.

Avant une investigation, appliquer la [méthode du projet](../docs/architecture/HLD.md#methodologie) :
question utile, données existantes, budget, signal et critère d'arrêt.
Intégrer les faits, hypothèses, décisions et apprentissages réutilisables
dans le document vivant concerné selon [l'index](../docs/INDEX.md).
Ne pas créer de note narrative, étude ou compte rendu séparé dans ce répertoire.
